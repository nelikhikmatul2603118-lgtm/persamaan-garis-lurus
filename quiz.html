Isi Halaman Quiz

Petunjuk: Pilih satu jawaban yang paling tepat untuk soal pilihan ganda. Untuk soal uraian, tuliskan langkah penyelesaian secara ringkas.

Soal Pilihan Ganda

1. Pada pasangan berurutan (3, 7), angka 3 menunjukkan ….

Kunci: A. Angka pertama pada pasangan (x, y) adalah koordinat x.

2. Pasangan manakah yang memenuhi persamaan y = 2x + 1?

Kunci: B. Untuk x = 2, y = 2(2) + 1 = 5, sehingga (2, 5) memenuhi.

3. Jika y = 3x dan x = 4, nilai y adalah ….

Kunci: C. Substitusi x = 4 menghasilkan y = 3 × 4 = 12.

4. Pasangan berurutan untuk x = 0 pada persamaan y = x + 3 adalah ….

Kunci: B. Jika x = 0, maka y = 0 + 3 = 3.

5. Langkah awal yang tepat untuk menggambar grafik persamaan adalah ….

Kunci: B. Pilih nilai x, hitung y, lalu susun pasangan berurutan.

Soal Uraian

6. Lengkapi tabel untuk persamaan y = x + 1 ketika x = -1, 0, 1, dan 2. Tuliskan pasangan berurutannya.

7. Apakah pasangan (2, 7) memenuhi persamaan y = 3x + 1? Tunjukkan perhitunganmu.

8. Jelaskan langkah-langkah menggambar grafik dari persamaan y = 2x.
