Isi Halaman Materi

Pelajari konsep dasar persamaan garis lurus di bawah ini.

1. Apa itu persamaan garis lurus?

Persamaan garis lurus adalah persamaan yang menggambarkan hubungan antara dua variabel dan grafiknya berupa garis lurus pada bidang koordinat. Pada tahap ini, fokus pembelajaran adalah memahami persamaan, pasangan nilai, dan cara menggambar grafik. Konsep gradien belum dibahas.

2. Mengenal variabel x dan y

Variabel adalah simbol yang mewakili nilai yang dapat berubah. Dalam pasangan (x, y), x merupakan koordinat mendatar dan y merupakan koordinat tegak. Nilai x dan y harus memenuhi persamaan yang sedang dipelajari.

3. Contoh persamaan linear sederhana

Contoh: y = 2x + 1. Untuk mendapatkan pasangan berurutan, pilih nilai x, lalu masukkan ke persamaan untuk memperoleh y.

x Perhitungan y = 2x + 1 Pasangan (x, y)
-1 y = 2(-1) + 1 = -1 (-1, -1)
0 y = 2(0) + 1 = 1 (0, 1)
1 y = 2(1) + 1 = 3 (1, 3)
2 y = 2(2) + 1 = 5 (2, 5)

4. Cara menggambar grafik persamaan

  1. Buat bidang koordinat Kartesius yang terdiri atas sumbu-x mendatar dan sumbu-y tegak.
  2. Tentukan beberapa nilai x yang mudah dihitung.
  3. Substitusikan setiap nilai x ke persamaan untuk memperoleh y.
  4. Tuliskan hasilnya dalam tabel dan pasangan berurutan.
  5. Letakkan setiap pasangan berurutan sebagai titik pada bidang koordinat.
  6. Hubungkan titik-titik tersebut dengan garis lurus jika titik-titik menunjukkan pola garis lurus.

5. Contoh penyelesaian

Gambarkan grafik y = x + 2 untuk x = -2, -1, 0, 1, dan 2.

  • Jika x = -2, maka y = -2 + 2 = 0, sehingga titiknya (-2, 0).
  • Jika x = -1, maka y = -1 + 2 = 1, sehingga titiknya (-1, 1).
  • Jika x = 0, maka y = 0 + 2 = 2, sehingga titiknya (0, 2).
  • Jika x = 1, maka y = 1 + 2 = 3, sehingga titiknya (1, 3).
  • Jika x = 2, maka y = 2 + 2 = 4, sehingga titiknya (2, 4).

Plot kelima titik pada bidang koordinat, kemudian hubungkan secara berurutan dengan garis lurus. Grafik membantu kita melihat hubungan nilai x dan y secara visual.
